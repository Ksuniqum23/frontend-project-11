Web app for subscribing to and reading RSS feeds in a unified interface.

## 🚀 Demo

[View the application](https://frontend-project-11-ruddy-nu.vercel.app/)


## ✨ Features

- RSS feed parsing and aggregation
- Asynchronous data loading with auto-updates
- Responsive UI design
- Modular JavaScript architecture

## 🛠️ Technologies

- HTML5 
- CSS3
- Vanilla JavaScript (ES6 modules)
- Vite
- RSS 2.0

## 🚀 Quick Start
```bash
# Clone repository
git clone https://github.com/Ksuniqum23/frontend-project-11.git
cd frontend-project-11

# Install dependencies
npm install

# Build project
npm run build

# Start dev server
npm run dev

After launching, the application is available at: http://localhost:5173/ or other port
